Notes / use cases
Import items

Columns: name, category, location, notes, status, taken_to, expiry_date — only name is required (location defaults to “Unspecified”).

  • A header row is optional. Without one, columns are read in the order above.
  • expiry_date accepts 2027-03-31, 31/03/2027 or just 03/2027 (end of that month).
  • status can be in or out; for out, put the current place in taken_to.
  • New categories are created automatically. Duplicate name + location pairs are skipped.
